# 微信小游戏发行指引

> 适用渠道：`wechat_minigame`　更新日期：2026-11-07

## 一、主体与资质

- **企业主体**：微信小游戏仅支持企业、政府、媒体等非个人主体注册；个人主体无法开通小游戏类目。注册前准备营业执照、对公账户与企业法人信息。
- **小游戏类目**：在微信公众平台选择「小游戏」类目，并按游戏内容选择二级类目（休闲、益智、角色扮演等）。类目决定后续资质要求。
- **软件著作权**：提交审核需提供与游戏名称一致的《计算机软件著作权登记证书》；名称不一致会被驳回，需提前完成软著登记（通常 30 个工作日，可加急）。
- **版号适用说明**：含内购、广告变现或联网对战的商业化小游戏需提供国家新闻出版署游戏版号（ISBN）；纯免费、无内购、无广告的休闲小游戏在部分类目可先上线试运营，但类目审核仍可能要求版号，务必在提审前确认类目政策。

## 二、AppID 与开发者工具

1. 登录微信公众平台，注册「小游戏」，获得 **AppID**。
2. 在「开发管理 → 开发设置」中记录 AppID，并配置服务器域名（如使用 `wx.request` 联网）。
3. 下载并安装 **微信开发者工具**（稳定版）。
4. 选择「导入项目」，目录指向渠道包解压后的根目录（含 `game.js`、`game.json`、`project.config.json`），填入 AppID。
5. 本渠道包默认写入 `project.config.json` 的 `appid` 为 `touristappid`（游客模式），正式提审前改为真实 AppID。

## 三、真机调试

1. 在开发者工具点击「真机调试」，用微信扫码在手机上运行。
2. 检查启动黑屏、音频、触摸、横竖屏、分包加载与 `wx` API 兼容性。
3. 关注控制台报错：`wx.createCanvas`、`wx.request`、`wx.getStorageSync` 等 API 是否被适配层正确代理。
4. 真机性能面板确认首屏加载时间与内存占用，避免因包体过大被限制。

## 四、上传与提审

1. 开发者工具点击「上传」，填写版本号与项目备注，生成开发版。
2. 登录微信公众平台「版本管理」，将开发版设为体验版，邀请测试。
3. 提交审核：填写功能页面、测试账号、类目资质、软著、版号（如适用）。
4. 审核通过后点击「发布」，全量上线；如需灰度，先按比例发布。

## 五、包结构

```
/
├── game.js                 # 入口，加载适配层与游戏 bundle
├── game.json               # 小游戏配置（屏幕方向、网络超时等）
├── project.config.json     # 项目配置（appid、compileType: game）
├── adapter/index.js        # DOM / Canvas / wx API 适配层
├── game/                   # 原始 Web 资源
│   ├── index.html
│   └── game.bundle.js
├── package-manifest.json   # 渠道包元数据
└── CHANNEL_GUIDE.md        # 本指引
```

## 六、常见失败

- **类目资质缺失**：小游戏类目未提交软著或版号，审核直接驳回。
- **名称不一致**：游戏名与软著登记名不一致，需改名或补充授权。
- **AppID 仍是 touristappid**：游客 AppID 无法提审，需改为企业主体 AppID。
- **DOM 依赖**：大量 `document.querySelector` / `innerHTML` 的网页游戏无法运行，需改为 Canvas 渲染。
- **服务器域名未配置**：联网请求报 `url not in domain list`，需在公众平台配置合法域名。
- **包体超限**：主包超过 4MB 未使用分包，上传失败。
- **首屏黑屏**：入口脚本未加载或适配层未初始化 `GameGlobal`。
