# 抖音小游戏发行指引

> 适用渠道：`douyin_minigame`　更新日期：2026-11-07

## 一、主体与资质

- **企业主体**：抖音小游戏面向企业开发者开放，需在「抖音开放平台」完成企业认证，准备营业执照、法人身份信息与对公账户。
- **软件著作权**：提审需提供与游戏名称一致的《计算机软件著作权登记证书》，建议提前 1 个月启动登记。
- **类目资质**：选择「小游戏」下对应二级类目，并按要求提交资质；涉及棋牌、捕鱼、传奇等特殊类目需额外审批，多数限制企业且有版号要求。
- **版号**：含内购、广告或联网对战的商业化游戏需提供游戏版号；纯免费休闲游戏按当前类目政策执行，提审前以开放平台类目说明为准。

## 二、AppID 与开发者工具

1. 登录抖音开放平台，创建「小游戏」应用，获得 **AppID**（也称 ClientKey）。
2. 在「开发设置」中配置服务器域名、支付与广告能力（按需）。
3. 下载并安装 **抖音开发者工具**。
4. 选择「导入项目」，目录指向渠道包解压后的根目录，填入 AppID。
5. 本渠道包默认写入 `project.config.json` 的 `appid` 为 `testappid`，正式提审前改为真实 AppID。

## 三、真机调试

1. 开发者工具连接手机或使用「真机调试」扫码运行。
2. 检查 `tt` API 兼容性：`tt.createCanvas`、`tt.request`、`tt.getStorageSync`、`tt.createImage`。
3. 验证横竖屏、触摸事件、音频自动播放限制与首屏加载。
4. 查看真机日志定位白屏、API 未定义或资源 404。

## 四、上传与提审

1. 开发者工具点击「上传」，填写版本号与变更说明。
2. 登录开放平台「版本管理」，设置体验版并邀请测试。
3. 提交审核：填写功能说明、测试账号、类目资质、软著、版号（如适用）。
4. 审核通过后发布上线；支持分阶段灰度发布。

## 五、包结构

```
/
├── game.js                 # 入口，加载适配层与游戏 bundle
├── game.json               # 小游戏配置
├── project.config.json     # 项目配置（appid、compileType: game）
├── adapter/index.js        # DOM / Canvas / tt API 适配层
├── game/                   # 原始 Web 资源
│   ├── index.html
│   └── game.bundle.js
├── package-manifest.json   # 渠道包元数据
└── CHANNEL_GUIDE.md        # 本指引
```

## 六、常见失败

- **企业认证未完成**：个人主体无法发布小游戏，需先完成企业认证。
- **软著缺失或名称不一致**：提审被驳回，需补充或变更软著。
- **类目资质不足**：特殊类目未提交版号或专项资质。
- **AppID 仍是 testappid**：测试 AppID 无法提审。
- **`tt` API 未适配**：直接使用 `wx` 或浏览器 API 导致真机报错。
- **服务器域名未配置**：请求被拦截，需在开放平台配置合法域名。
- **启动项缺失**：`game.js` 未加载适配层，出现白屏。
